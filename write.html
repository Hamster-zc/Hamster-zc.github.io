WRITE SOMETHING DOWN

写一篇新文章.

填写信息后下载 Markdown 文件，再上传到 GitHub 仓库的 posts 文件夹。分类可以写成“学习 / NLP”，关键词标签可以填多个。

文件名会根据标题自动生成
发布步骤：下载文件 → 在 GitHub 仓库打开 posts 文件夹 → Add file → Upload files → 提交。网站会自动更新。
本地上传则把文件放入 C:\ZC\Blog\posts，运行 npm run build，再提交并推送。
